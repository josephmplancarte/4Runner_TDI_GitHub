# Firmware and software

**Not included in the supplied ZIP:** Arduino `.ino` and other firmware source files.

When available, place the transmission controller's source code, relevant configuration and build instructions in this folder. Include a pin map, program version, hardware revision, and a test log so the project can be reproduced and understood. Do not upload passwords, account credentials, or private key files.

The presence of a completed PCB does **not** imply firmware validation.
